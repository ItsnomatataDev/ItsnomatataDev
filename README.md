## 🧭 Who We Are

**IT's No Matata** is a technology company based in **Victoria Falls, Zimbabwe**, engineering scalable digital infrastructure, AI-powered systems, and modern operational platforms for businesses across Africa and beyond.

We combine **realtime architecture**, **intelligent automation**, **AI engineering**, and **production-grade UI** to transform how organizations operate — designed specifically for the speed, scale, and realities of African markets.

> If your tools weren't built for Africa, they weren't built for you. We fix that.

<br/>

## 🚀 Codex — The Flagship Platform

<div align="center">

### **[codex.itsnomatata.com](https://codex.itsnomatata.com)**

*An AI-native workspace OS — built for African teams that move fast.*

</div>

<br/>

**Codex** is not another project management tool. It is an **AI-native operational platform** that unifies team communication, task management, workflow automation, and real-time collaboration into a single, mobile-first environment — purpose-built for organizations operating across Africa.

<br/>

<div align="center">

| Feature | Description |
|:---|:---|
| 🏢 **Organization Management** | Full multi-org support with structured workspaces |
| 🔐 **Role-Based Workspaces** | Granular access control and workspace isolation |
| 🤖 **AI-Assisted Operations** | Intelligent suggestions, smart automation, decision support |
| ⚡ **Realtime Communication** | Live presence, instant messaging, zero-refresh collaboration |
| 📋 **Boards & Task Management** | Visual workflows, sprint boards, and team coordination |
| 📱 **Mobile-First Architecture** | Built for the field — not just the office |
| 🔄 **Workflow Automation** | Smart triggers that eliminate repetitive operational tasks |
| 📴 **Offline Capability** | Works reliably in low-connectivity environments |

</div>
